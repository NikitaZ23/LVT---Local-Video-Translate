# LVT - Local Video Translate

LVT - локальное приложение для перевода видео в субтитры и русскую озвучку. Облако и регистрация не нужны: видео остается на компьютере, а результат сохраняется как `.vtt`, `.wav` или `.mp4`.

## Как работает

1. LVT берет путь к видеофайлу или папке.
2. `ffmpeg` извлекает аудио во временную рабочую папку.
3. `whisper.cpp` распознает речь и создает субтитры с таймкодами.
4. `Argos Translate` переводит текст субтитров.
5. Если выбрана озвучка, Silero TTS создает русскую дорожку `.wav`.
6. FFmpeg собирает `.mp4` с оригинальным звуком потише и русской озвучкой поверх.

Без режима озвучки голос в видео не меняется. Перевод появляется только как субтитры на экране.

## Запуск

```powershell
cd "C:\Users\User\Documents\ChatGPT\LVT"
npm run dev
```

Открыть:

```text
http://localhost:5190
```

## Что нужно установить отдельно

- Node.js 20 или новее.
- FFmpeg с `ffmpeg.exe`, например `E:\AI\Tools\ffmpeg-release-essentials\ffmpeg-9.0.1-essentials_build\bin\ffmpeg.exe`.
- whisper.cpp CPU: `E:\AI\Tools\whisper-bin-x64\whisper-cli.exe`.
- whisper.cpp GPU/CUDA: `E:\AI\Tools\whisper-cublas-12.4.0-bin-x64\Release\whisper-cli.exe`.
- Модель Whisper, например `ggml-large-v3-turbo.bin`.
- Python для Argos Translate: `C:\Users\User\Documents\ChatGPT\LVT\.venv\Scripts\python.exe`.
- Модель Silero TTS для русской озвучки: `E:\AI\Models\Silero\v5_5_ru.pt`.

Для проверки без перевода можно выбрать режим **Без перевода: только распознать речь**. Тогда Argos Translate не нужен.

## Режимы

- **Один файл** - обработать один видеофайл.
- **Папка с видео** - просканировать папку, обработать все найденные видео и получить локальный плейлист результатов.

В режиме папки есть три варианта названий в плейлисте:

- **Не переименовывать** - оставить имя файла без расширения.
- **Папка + видео** - например `Модуль_Интро`.
- **Плейлист + видео** - например `Курс_Интро`.

Локальные видеофайлы не переименовываются.

В шаге **Локальные модели** можно выбрать, где запускать Whisper:

- **Видеокарта NVIDIA** - использует CUDA/cublas-сборку whisper.cpp.
- **Процессор** - использует обычную CPU-сборку whisper.cpp.

## Где сохраняются субтитры

Можно выбрать:

- **В рабочей папке LVT** - исходные папки остаются чистыми.
- **Рядом с исходным видео** - рядом с `lesson01.mp4` появится `lesson01.ru.vtt`, а при озвучке еще `lesson01.ru.voice.wav` и `lesson01.ru.voiceover.mp4`.

Пример рабочей папки:

```text
C:\AI\LVT-Work
```

Пример папки с моделями:

```text
E:\AI\Models
```

Важно: папка `E:\AI\Tools\ffmpeg-9.0.1` должна содержать готовый `bin\ffmpeg.exe`. Если там лежат только `configure`, `libavcodec`, `fftools` и другие исходники, это source-архив FFmpeg, а не Windows-сборка.
